# 國際扶輪 3523 地區活動整合報名系統 (Rotary District 3523 Event Registration SPA)

本專案為國際扶輪 3523 地區年度常態活動之整合報名系統單頁應用程式 (Single Page Application, SPA)，專為扶輪社各社執秘、社長、主委與地區幹部設計，支援各作業系統與行動裝置連動。

---

## ✨ 系統核心功能

1. **✍️ 各社執秘專用工作區**
   - 內建 3523 地區 1~13 分區各扶輪社標準名冊庫。
   - **⛳ 高爾夫差點 (Golf Handicap) 整合庫**：維護社友資料時支援登記 0~54 高爾夫差點，勾選自動帶入報名表，即時動態計算全隊平均差點。
   - 一鍵勾選免重複 Key-in，自動帶入職務、Nick Name、葷素需求。
   - 防竄改社別鎖定機制。
   - **🎁 贊助獎登錄**（運動賽事）：執秘可直接點選本社社友（如總監、地區賽事主委、地區秘書長）登錄贊助獎，可選「現金（填金額）」或「禮品（填名稱）」並勾選是否用餐；勾選用餐者自動列入用餐人數與葷素統計，免餐費、不計入該社應繳總計；同步顯示於 LINE 通報、主委儀表板、名單明細與 Excel 匯出；主委「全部展開（合併 Excel/CSV）」檢視、複製全體名冊與 Excel 另有「全體贊助獎彙整」，不分社集中列出並附合計。

2. **📊 當屆主委戰情儀表板**
   - **🗂️ 收合式面板，新手主委也看得懂**：主委後台與最高權限管理頁的每個區塊預設收合，標題下方一句白話說明「點開可以做什麼」，想看再按「展開」；展開狀態會記在該裝置，另有「全部展開／全部收合」。最上方固定顯示報名人數、葷素、贊助金額、封存狀態四格總覽。
   - 即時報名人數、葷食/素食、贊助累計金額統計。
   - 針對「地區高爾夫球聯誼賽」自動切換選手差點戰情報表。
   - 各社已提交報名明細與出席名單（含差點）一鍵展開檢視。
   - 模擬活動當日 00:00 自動封存唯讀機制。
   - **🧪 示範資料（最高管理員）**：最高權限管理頁可「載入示範資料」供展示用，系統啟動時不會自動生成模擬資料。「一次清空全部繳費紀錄／報名單／社友庫」的按鈕已移除，避免誤刪；要清空資料請用主委後台的「📦 歷屆備份與清空本活動」，逐活動先備份再清空。
   - **🏢 地區辦公室不列入繳費名單**：「地區辦公室」僅供指派為活動主委（地辦人員協助後台），繳費總表、催繳名單、投影模式與 Excel 匯出皆以 80 社計算，不含地區辦公室。
   - **💳 繳費狀況依子活動分開**：各分區各社繳費狀況即時總表以「子活動」為單位各自一張（GMS、DTLS、年會大會…互不影響），應繳金額自動帶入該子活動的「各社應繳金額」；執秘送出報名表不會自動標記為已繳費，由主委手動核訖或貼上銀行通知核對。
   - **🔒 主選單與子活動增刪僅限最高管理員**：「新增/刪除主選單」、「新增/刪除子活動」四個按鈕只有最高管理員登入後才會顯示，活動主委與各社執秘進入時完全看不到，也無法操作。
   - **📎 活動DM（海報／簡章）上傳**：主委在「活動設定與費用金額」面板點開「活動DM」，可上傳 PDF、JPG、PPT／PPTX（每檔最大 20 MB，可多檔），各社執秘在報名頁標題下方會看到「📎 活動DM」連結可開啟或下載；每個子活動各自一組檔案，主委可刪除舊檔。檔案存放於 Supabase Storage（需先依下方「活動 DM 檔案空間設定」建立一次）。
   - **💳 匯款帳號與上海商銀入帳通知自動對帳**：主委在「活動設定與費用金額 → 匯款帳號與入帳通知信箱」填寫匯款帳號、銀行通知信寄達的信箱帳密與通知單 PDF 開啟密碼（戶名統編／身分證末六碼）；執秘在**每個活動**的報名頁都會看到匯款帳號、應繳金額（運動賽事等為本社報名表總計）與「匯款備註請填貴社全名（例：南區扶輪社）」提醒，**匯款後不需要另外回報**。雲端小程式每 10 分鐘讀取信箱中的上海商銀「入帳通知單」，解開加密 PDF 附件取出存摺備註與金額，依「備註中的社名＋金額」比對後自動標記「已繳費（Email 自動核對）」，執秘端同步顯示「✅ 已收到您的匯款」；主委可按「立即抓取」、檢視所有入帳紀錄，未配對的入帳可手動指定給某社。需先依下方「入帳通知自動對帳設定」完成一次設定。
   - **💰 各子活動獨立費用設定**：參賽選手費、只用餐費、共同主辦社/協辦社/贊助社金額、研習會每社應繳金額、社慶花款與餐費，皆依「子活動」分別儲存，高爾夫、保齡球、各社社慶可各自設定不同金額，互不覆蓋。

3. **📲 跨作業系統與手機行動端連動中心**
   - **動態 QR Code 掃碼**：使用 iPhone / Android 手機直接掃碼即可於行動端瀏覽器開啟。
   - **原生系統分享 (Web Share API)**：一鍵呼叫手機原生選單，直接轉發至 LINE、AirDrop 或各大 App。
   - **💬 LINE 扶輪一鍵通報**：針對台灣扶輪社溝通習慣，一鍵格式化產出出席名冊（含職稱、姓名、Nick Name、葷素、**高爾夫差點**）並直接開啟 LINE 傳送。執秘報名頁的「⚡ 行動快捷功能」列即有「📲 一鍵傳送到 LINE 群組」按鈕，手機點擊會直接開啟 LINE 選擇群組並帶入名冊文字；電腦需安裝 LINE 桌面版才會開啟，否則請改用「💬 複製 LINE 報名名冊」貼上。
   - **🤖 AI 小幫手**：執秘報名頁「⚡ 行動快捷功能」列的「🤖 AI 小幫手」按鈕會開新分頁到地區的 AI 問答系統（Agentic RAG），並自動帶入目前綁定的社名，輸入該系統的社密碼即可詢問「我們社報名了什麼、報了誰、繳費了沒、匯款帳號」等問題（AI 只能查詢自己社的資料，問其他社會被拒絕），也能查扶輪知識文件。網址設定在 `index.html` 開頭的 `RAG_ASSISTANT_URL`，留空則不顯示按鈕。
   - **📅 行事曆連動 (.ics & Google Calendar)**：支援匯出標準 `.ics` 檔案與一鍵加入 Google 日曆。
   - **💾 跨裝置備份與同步代碼**：本機 LocalStorage 自動持久化保存，支援一鍵產生同步字串代碼跨裝置貼上還原，以及 JSON 備份檔匯出/匯入。
   - **📥 跨平台無亂碼 Excel (CSV)**：採用 UTF-8 BOM (`\uFEFF`) 編碼，徹底根除 Windows 繁體中文 Excel 亂碼問題。
   - **PWA 行動端優化**：支援 iPhone「加入主畫面」全螢幕運行如原生 App。

4. **🔄 生命週期規格與 E-R Schema 檢視**
   - 清楚展示年度換屆資料銜接邏輯（清空當屆報名，但永久留存各社執秘社友資料庫與高爾夫差點）。

## 活動 DM 檔案空間設定（最高管理員只需做一次）

活動 DM 的檔案本體存放在 Supabase Storage 的 bucket `event-dm`。第一次使用前請在 Supabase 後台建立：

1. 登入 https://supabase.com/dashboard ，進入本系統的專案。
2. 左側選單點 **SQL Editor** → **New query**。
3. 貼上下面整段 SQL，按 **Run**：

```sql
-- 建立公開讀取的 bucket「event-dm」，單檔上限 20 MB，只允許 PDF / JPG / PPT / PPTX
insert into storage.buckets (id, name, public, file_size_limit, allowed_mime_types)
values ('event-dm', 'event-dm', true, 20971520,
        array['application/pdf', 'image/jpeg',
              'application/vnd.ms-powerpoint',
              'application/vnd.openxmlformats-officedocument.presentationml.presentation'])
on conflict (id) do update set public = true, file_size_limit = 20971520,
  allowed_mime_types = excluded.allowed_mime_types;

-- 前端用 anon key 直接上傳／讀取／刪除，所以要對 anon 開放 event-dm 這個 bucket
create policy "anon read event-dm"   on storage.objects for select to anon using (bucket_id = 'event-dm');
create policy "anon upload event-dm" on storage.objects for insert to anon with check (bucket_id = 'event-dm');
create policy "anon update event-dm" on storage.objects for update to anon using (bucket_id = 'event-dm');
create policy "anon delete event-dm" on storage.objects for delete to anon using (bucket_id = 'event-dm');
```

4. 看到 `Success` 即完成。回到系統，以主委身分在「活動設定與費用金額 → 活動DM」上傳一個檔案測試。
5. 若上傳時出現「雲端尚未建立 event-dm 儲存空間」或「存取權限尚未開放」的提示，代表上面的 SQL 沒有成功執行，請重新執行一次。

## 入帳通知自動對帳設定（最高管理員只需做一次）

這個功能需要三樣東西：① 雲端資料表與排程、② 讀信的雲端小程式、③ 收銀行通知信的信箱帳密與通知單 PDF 的開啟密碼。

### ① 建立資料表與每 10 分鐘排程

1. 開 https://supabase.com/dashboard/project/ncrvmhfggfczicpyebvn/sql/new 。
2. 把專案裡 `supabase/sql/bank_mail_setup.sql` 的整段內容貼上，按 **Run**，看到 Success 即可（可重複執行）。
   它會建立 `bank_transactions`（入帳紀錄，前端可讀）、`bank_mail_settings`（信箱與密碼，**前端只能寫不能讀**，密碼不外洩）、`bank_mail_status`（抓取狀態），並用 pg_cron 每 10 分鐘呼叫一次雲端小程式。

### ② 部署雲端小程式 `fetch-bank-mail`

在這台電腦的終端機（或 Claude Code 對話中用 `!` 開頭）依序執行：

```bash
supabase login                      # 會開瀏覽器登入 Supabase 帳號，登入一次即可
cd "/Users/fruit/Documents/insta360/01扶輪/3523報名表"
supabase link --project-ref ncrvmhfggfczicpyebvn
supabase functions deploy fetch-bank-mail --no-verify-jwt
```

`--no-verify-jwt` 是讓排程與前端都能直接呼叫；這支小程式只會「去讀信並寫入入帳紀錄」，不會回傳任何密碼或私人資料，且 20 秒內重複呼叫會自動略過。

### ③ 填入收通知信的信箱、密碼與 PDF 開啟密碼

上海商銀的入帳通知信**本文沒有金額**，入帳明細放在一個**加密 PDF 附件**裡，開啟密碼是帳戶戶名的「身分證號或統一編號末六碼」。所以後台要填三樣：信箱帳號、信箱密碼、PDF 開啟密碼。

1. 確認上海商銀的入帳通知寄到哪個信箱（網路銀行「服務類 → 電子郵件服務設定」可查看或變更）。
2. 以主委或最高管理員身分進「活動設定與費用金額 → 匯款帳號與入帳通知信箱」：
   - **信箱服務**：HiNet（ms○.hinet.net 結尾的中華電信信箱）直接選 HiNet，密碑用平常登入信箱的密碼即可。
     若是 Gmail：先到 Google 帳戶 → 安全性 → 開啟「兩步驟驗證」，再到 https://myaccount.google.com/apppasswords 建立一組 16 碼「應用程式密碼」，填這組而不是登入密碼。
   - **Email address**、**Email 密碼**。
   - **PDF 開啟密碼**：戶名的身分證號／統一編號末六碼（6 碼數字）。
3. 按「儲存信箱並測試連線」。幾秒後狀態列出現「掃描 N 封，其中銀行通知 N 封，新增入帳 N 筆」且沒有紅字就成功了；「③ 銀行入帳紀錄」會列出最近 60 天所有入帳。
4. 常見紅字：「信箱登入失敗」→ 帳號或密碼打錯；「PDF 開啟密碼錯誤」→ 末六碼不對；「連不上收信主機」→ 信箱服務選錯。
5. **HiNet 信箱要先關掉「海外登入限制」**：雲端小程式在國外的伺服器執行，HiNet 預設不允許非臺灣 IP 登入，會回「LOGIN failed. Invalid login/password.」（明明帳密正確）。到 https://webmail.hinet.net 登入 → 設定 → 環境設定 → 「登入來源限制設定」，把 **POP3/IMAP 的「不允許非臺灣 IP 登入」取消勾選** 後儲存（網頁郵件那一項可維持勾選）。
6. 第一次設定時信箱裡可能已累積幾十封通知，雲端每次只處理 4 封（平台 CPU 限制），按「立即抓取」會自動一輪一輪續抓到做完；之後排程每 10 分鐘抓一次，平常一天幾封不會有這個問題。

### 重新上傳雲端小程式（程式有更新時）

在 Finder 開啟專案資料夾，點兩下 **「部署雲端小程式.command」**，看到 ✅ 上傳成功即可（第一次若被 macOS 擋下，對檔案按右鍵 → 打開）。

### 比對規則（讓主委了解為何有些入帳要手動指定）

執秘匯款後不需要回報，系統只看銀行通知信上的「存摺備註」與「金額」：

- 存摺備註含有某一社的社名關鍵字（例如「南區」「松山」），且只對得上一個社（「西南區」不會被「南區」搶走）。
- 入帳金額正好等於該社某個**尚未繳費**活動的應繳金額：研討會／年會／分攤金＝主委設定的各社應繳金額；運動賽事、社慶等＝該社報名表的總計。
- 同一個主選單裡有多個同金額的未繳項目（例如上半年、下半年分攤金）→ 先沖銷排在前面的那一項。
- 同金額的未繳項目分散在不同主選單 → 系統無法判斷，留給主委指定。
- 其餘情況（備註空白、亂碼、金額不符）會留在「未配對」，主委在入帳紀錄右側選社別按「指定」即可。

## 社長當選人學習研討會 (PELS)：依出席方式收費與旅平險資料

子活動名稱含「PELS」或「社長當選人」時，系統自動切換成這個模式：

- **主委「活動設定與費用金額」**：不顯示「每社應繳金額」，改為四個費用欄位——① 本人單獨出席－2人1房（每人）② 本人與眷屬共同出席－2人房 ③ 本人單獨出席－指定住單人房 ④ 不克參加（需補課）請假理由。
- **先設定費用才開放報名**：四種出席方式的費用都還是 0 時，執秘端會顯示「主委尚未設定費用，暫不開放報名」且無法送出；主委填入金額並按「儲存主委設定」後立即開放。
- **執秘報名**：每位報名者選一種出席方式，費用自動加總為本社應繳金額；選「不克參加」要填請假理由。
- **旅平險資料**：出席者（含眷屬）必須填身分證字號、民國出生年月日、手機號碼，系統會檢查格式。＊個資僅用於旅平險。
- **個資保護**：身分證字號、生日、手機**不會**存進一般報名資料，也不會顯示在名冊、LINE 文字或任何畫面上；送出後連執秘自己也只看到「已送出」。主委要在「出席方式總覽與旅平險名單」面板輸入「個資檢視密碼」才能匯出 Excel 交給保險公司；活動結束後可在同一個面板刪除全部個資。
- **個資檢視密碼**：與登入密碼不同，第一次由主委或最高管理員在面板上設定（至少 8 個字），之後變更需輸入舊密碼。忘記密碼只能請系統維護人員到 Supabase 重設。

### 旅平險個資保存空間設定（每個地區的資料庫只需做一次）

到 Supabase → SQL Editor，把 `supabase/sql/insured_persons.sql` 整段貼上執行。沒有執行的話，PELS 報名送出時會提示「雲端尚未建立旅平險個資保存空間」而無法送出（刻意如此，避免個資被存到公開的地方）。

## 地辦分攤金／配合款：各分區繳款達成率圖表

主委（或被指派為主委的地區辦公室）進入「地辦分攤金/配合款」或任何名稱含「分攤金」「配合款」的子活動時，後台最上方會出現「各分區繳款達成率」圖表：

- 上方四格：全區達成率、尚未繳款社數、實收金額（對照應收）、全數繳清的分區數。
- 每個分區一條橫條：深色＝已繳款的社，灰色＝尚未繳款；右邊是達成率與「已繳社數／分區社數」。
- 橫條旁直接列出該分區**尚未繳款的社名**。
- 可切換「依分區順序」或「達成率低的在前」。
- 資料與下方的繳費總表完全同步，主委核訖後圖表立刻更新。
- 按「📄 匯出 PDF（簡報用）」會下載一頁 A4 橫式的「各分區繳款達成率報告」（含地區名稱、年度、項目名稱、資料時間、四格摘要、各分區達成率橫條、分區實收與未繳社名），可直接投影或放進簡報。排序方式跟著畫面上的選擇。第一次匯出需要網路（要下載 PDF 產生元件）。

## 貼上 LINE 接龍，自動勾選報名名單

社內通常先在 LINE 群組接龍，再由執秘報名。社友多時不必一個一個勾：

1. 在 LINE 群組長按接龍訊息 →「複製」。
2. 回到報名系統，在「○○扶輪社 社友庫」右上角按「💬 貼上 LINE 接龍」，把文字貼進框框（或按「從剪貼簿貼上」），再按「辨識名單」。
3. 系統會列出：**找到的社友**、**需要人工處理**的行（社友庫裡找不到這個名字，或同名無法判斷）、**略過**的行（取消／請假）。
4. 按「帶入報名表」，找到的社友就會全部勾選好。檢查無誤後按「送出本社報名表」。系統不會自動送出。

比對規則：

- 用社友庫裡的**中文姓名**或 **Nick Name** 比對，大小寫、全形半形、空白、連字號都不影響（`C-Wang`＝`C Wang`＝`CWang`）；Nick Name 前面的扶輪職稱（P、PP、PDG、PAG…）有寫沒寫都認得（接龍寫 `PAG LED`、社友庫登記 `LED`，或反過來，都對得上）。
- 「+1」「夫婦」「伉儷」「+夫人」會一併勾選該社友的寶(尊)眷（社友庫裡要先建好眷屬資料）。
- 運動賽事中，行內寫「只用餐」的社友會自動設成只用餐。
- 含「取消」「請假」「不克」的行會略過；若同一個人前面接龍、後面又寫取消，會從名單中拿掉。
- 接龍的標題、時間、地點等沒有編號的行會自動忽略。

## 活動報到（活動當天櫃台點名）

活動當天，櫃台工作人員用電腦、平板或手機開啟「報到頁」，在名單上點一下就完成報到。多個櫃台可以同時點名，彼此的結果幾秒內就會互相看到，不會蓋掉。

**哪些活動可以報到**：所有子活動都可以，不必另外設定；只有「分攤金／配合款」沒有報到（那只是繳款項目）。同一天的多個子活動（例如年會的大會與晚宴）各有自己的名單與報到網址。

### 主委：活動前與活動當天

1. 登入後切到該活動，在主委後台點開「🎫 活動報到」面板。
2. 按「設定報到密碼」（至少 4 個字）。這組密碼是給櫃台工作人員用的，請不要用貴社的登入密碼。
3. 把「報到頁網址」（可按「複製網址」，或讓工作人員掃面板上的 QR Code）與報到密碼交給工作人員。
4. 活動開始前按「▶ 開始報到」；結束後按「⏹ 結束報到」。只有「報到中」的時候櫃台才能點名，這樣網址就算外流也不會有人提前亂點。需要補登時可以再按「重新開始報到」。
5. 面板上會即時顯示應到、實到、未到、現場加報人數。
6. 「重新設定報到密碼」後，所有櫃台都會被退回輸入畫面，要用新密碼重新進入。
7. 「清空報到紀錄」只在活動前測試完、要歸零時使用，清空後無法復原。

### 櫃台工作人員：報到頁

- 開啟網址後輸入報到密碼與櫃台名稱（選填，例如「第一分區櫃台」，會記在每一筆報到紀錄上）。這台裝置會記住密碼，重新整理不必重打。
- **報到**：在搜尋框輸入姓名、Nick Name 或社名（大小寫、全形半形、空白都不影響），或用分區下拉選單找人，按「報到」。點錯可以按「取消」。
- 每個社的標題會顯示「已到／應到」人數，以及該社是否已繳費（尚未繳費會顯示金額，方便櫃台提醒）。
- 每個人會標示素食、參賽／只用餐、PELS 出席方式等，方便發餐券或資料袋。
- **現場加報**：沒報名卻到場的人按「➕ 現場加報」，選分區與社、輸入姓名（社友會出現在建議清單，名冊外的來賓直接輸入姓名即可）。加報時要選「已到」（加報並完成報到）或「還沒到」（例如社友先幫他報名：先加入名單，人到了再在名單上按「報到」；加錯可以按「刪除」）。已報到的人按「取消」只會取消報到，名字仍留在名單上，現場加報的人也一樣；要把加報的人從名單拿掉，請在他「尚未報到」的狀態下按「刪除」。現場加報**只記在報到紀錄裡**，不會更動該社的報名表與應繳金額，費用請主委活動後處理。
- **統計分頁**：應到／實到／未到／現場加報、出席率、實到的葷素人數、各分區與各社明細。「實到」是現場實際人數，已包含現場加報；出席率只算有報名的人。各社名單會列出所有人（含現場加報），**紅色＝已報到**、灰色＝尚未報到；可「匯出 Excel」（報到明細、各社統計、各分區統計三個工作表）或「複製未到名單」貼到 LINE。
- PELS 的「不克參加」不列入應到名單；「攜眷」只點報名者本人，眷屬隨同報到（眷屬姓名屬於受保護的個資，不會出現在報到頁）。

### 請留意

- 報到頁只會「讀取」報名資料，不會修改任何報名表，所以櫃台裝置開一整天也不會影響各社的報名。
- 報到密碼只是避免無關的人誤入。本系統沒有真正的帳號登入，無法防止懂技術又刻意搗亂的人，防護程度與整個報名系統相同。
- 報到需要網路；現場網路不穩時，點名會顯示失敗並請您重試，不會默默遺失。

### 活動報到資料表設定（每個地區的資料庫只需做一次）

到 Supabase → SQL Editor，把 `supabase/sql/event_checkins.sql` 整段貼上執行（可重複執行；這份檔案有更新時再執行一次即可，既有報到紀錄不受影響）。沒有執行的話，主委後台的「活動報到」面板會顯示「雲端尚未建立報到資料表」，其他功能不受影響。

## 歷屆備份與清空單一活動

主委後台的「📦 歷屆備份與清空本活動」面板：

- **查看歷屆資料**：活動主委與最高管理員都可以看到這個活動以前各屆的備份，按「👁 查看」看各社報名人數、金額、繳費狀態與名單，按「📥 Excel」下載完整資料（摘要、各社彙總、報名明細、繳費紀錄、銀行入帳、報到紀錄）。
- **備份並清空（只有最高管理員）**：上線前或換主委後，先切到要處理的活動，按「📦 備份並清空本活動」。系統會先把這個活動目前的報名表、繳費紀錄、銀行入帳、報到紀錄存成一份備份（可取名，例如「2026-27 年度」），確認備份成功後才清空報名表與繳費紀錄，並另外下載一份備份檔到電腦。**一次只處理一個活動，其他活動不受影響**；費用設定、活動日期、DM、主委指派都會保留。備份失敗時不會清空。
- **全部活動的備份總覽（只有最高管理員）**：面板裡按「📚 全部活動的備份總覽」，一次列出所有活動、所有屆別的備份（報名社數與人數、已繳社數、已收／應收金額），可依屆別篩選、逐筆查看或下載，也可「匯出總覽 Excel」做歷年比較。
- **活動結束後自動提醒備份**：活動結束滿一週、資料還沒有備份並清空時，系統會在當天晚上 8 點用 LINE 提醒「系統管理者」（每個活動只提醒一次）。系統管理者在行事曆後台「⑥」指定，可以多人（本人＋備援人員），要先在 LINE 綁定身分。提醒只是通知，備份並清空仍要登入報名系統操作。
- **扶輪年度自動換算**：頁面上的年度與備份的預設名稱依日期自動計算（每年 7/1 換年度），不必每年修改設定。
- 備份存在雲端後不能修改也不能刪除，可留作歷年統計。
- 首次使用前，請在 Supabase SQL Editor 執行 `supabase/sql/event_archives.sql`。

## 扶輪行事曆（LINE 裡的地區／社內／私人行事曆）

社友在 LINE 裡就能查看三種行程，疊在同一個月曆上：**地區行程**（藍色，全地區看得到）、**社內行程**（金色，只有本社看得到）、**私人行程**（綠色，只有自己看得到）。

- **怎麼打開**：把 `https://liff.line.me/<LIFF ID>?p=calendar` 設成 LINE 官方帳號選單的「行事曆」按鈕。第一次使用會先請社友綁定身分（與 LINE 自助報到共用同一份綁定）。
- **看行程**：上排切換「所有行程／地區／社內／私人」，下排切換「今天／三天／本週／本月」，可按 ‹ › 看前後。本月是月曆格，點某一天會顯示當天行程。系統會記住上次的選擇。
- **社內例會也能按「我要參加」，還可以一起勾選寶尊眷**：新增社內行程時預設會勾選「開放社友按『我要參加』」（社內例會、聯誼等不需要報名的活動用）。社友在 LINE 按「我要參加」時，下方會列出社友庫裡登記的寶尊眷，勾選誰就一起登記，名字自動帶出，不用另外輸入。社內社友都看得到名單（寶尊眷會標示），人數把寶尊眷也算進去。要取消時，本人與帶的寶尊眷會一起取消。主委或執秘可以在「行事曆管理」的行程列表按「看名單」查看並複製貼到 LINE。
- **行程預設開放「我要參加」**：新增地區或社內行程時，「開放社友按我要參加」預設就是打勾的（例會、運動賽事、研討會等全部一樣），主委填活動日期自動建立的行程也一樣；不想開放的行程，編輯時取消勾選即可。
- **社友名單排序**：社友庫、行事曆管理裡的社友名單，以及社友在 LINE 綁定時選名字的清單，都依「P（現任社長）→ S（現任秘書）→ 其餘依 Nick Name 字母順序」排列（P、S 可以寫在職務欄，也可以寫在 Nick Name 開頭，例如「P Robert」「S Three M」；排序時忽略 Nick Name 開頭的 PP、PE 等職稱，例如「PP Fred」以 Fred 排），寶尊眷排在對應社友的下方，方便查找（只改顯示順序，不影響資料）。
- **社友職務可自行輸入**：新增／編輯社友時，「今年扶輪職務」選單最後一項「✏️ 其他職務（自行輸入）」可手動填寫選單裡沒有的職務（例如地區秘書長、助理總監，最多 20 個字）。自填的職務只記在該社友身上，不會加進選單。
- **總監秘書代管總監的行事曆**：在行事曆後台被設為「總監秘書」的人，LINE 行事曆上方會多一個「👔 管理總監的行事曆」按鈕。按下後可以看到總監的全部行程（地區、總監所屬社、總監的私人行程），並可代總監新增、修改、取消、刪除私人行程；這些行程存在總監名下，總監自己看得到，每晚的推播也會包含。另外，總監秘書在自己的行事曆新增私人行程時，可勾選「🤝 同時加入總監的行事曆」（預設勾選），兩人的行事曆都會出現同一筆，任一方修改兩邊同步，不用重打一次。總監秘書對地區或社內活動按「我要參加」時，同樣可勾選「🤝 同時加入總監的行事曆」（預設勾選），總監的私人行事曆與每晚推播就會包含這個活動。
- **💰 即時報名／繳費狀況（給總監、總監秘書與指定的人）**：LINE 行事曆右上角的「💰 報名」會列出各活動的即時進度——分攤金、配合款顯示已繳社數、比例與已收／應收金額；研討會、年會、運動賽事等另外顯示報名社數與人數。點卡片可看各分區達成率與未繳社名，數字與主委後台的圖表是同一套算法。有對應報名活動的行程，詳細頁也會顯示這個活動的摘要。**總監、總監秘書**自動看得到全部活動；其他人（例如活動主委、地區辦公室人員）由管理者在行事曆後台「⑤ 誰可以在 LINE 看報名／繳費狀況」逐活動指定個人（可多選、可跨社，也可選「全部活動」）。一般社友看不到這些數字。打開、按「重新整理」或切回 LINE 時會抓最新資料。
- **執秘代為登記參加**：有些社友（例如長輩）不用 LINE，執秘可在「🗓️ 行事曆管理」的本社行程按「🙋 代為登記參加」，從社友庫勾選要幫忙登記的人（寶尊眷也可以勾），按「儲存」後，他們就會出現在 LINE 的參加名單（標「執秘代登記」），也會算進表示參加人數、實際出席的預設勾選與例會統計。社友自己在 LINE 登記的人會鎖住，要取消請本人在 LINE 按「取消參加」。只限開放參加（或有對應報名活動）的社內行程，已取消的行程不能再登記。
- **出席率查詢與匯出（例會＋補出席）**：出席率＝(例會出席＋補出席) ÷ 已記錄出席的例會場數。分母固定是本社例會，所以補出席多的社友出席率可以超過 100%；另外也列出不含補出席的「純例會出席率」。補出席有兩種來源：地區活動有現場報到的會**自動**計入；參加友社例會等，由執秘在「📈 出席率」點社友姓名後**手動登記**（日期、類別、說明），登記錯了也可以刪除。期間以扶輪年度計算，上半年＝7/1～12/31、全年＝7/1～隔年 6/30，也可以看上個年度。
  - **社友本人**：在 LINE 行事曆右上角按「📊 出席」，看自己上半年與全年的出席率，以及每場例會（出席／缺席／尚未記錄）與地區活動補出席的明細。
  - **社長（P）與秘書（S）**（預設；各社執秘可在報名系統「📈 出席率」右上的「⚙️ LINE 上誰可以看全社」改成勾選的人，例如加上前社長、理事，或恢復預設；行事曆後台「③」也能替任何一社設定）：同一頁多一個「👥 看全社出席率」，可以搜尋社友、點進去看每個人的明細，也可以「複製全社出席率」貼到 LINE。
  - **執秘**：報名系統「🗓️ 行事曆管理」的「📈 出席率」分頁，看全社每位社友上半年／全年的出席率，可搜尋、點姓名看明細、「⬇️ 匯出 Excel」（出席率總表、例會出席明細、補出席明細三個工作表）。
  - 注意：例會要執秘在「✅ 記錄實際出席」按儲存後才會列入；地區活動要現場報到（LINE 掃碼或櫃台點名）才會自動算補出席，只報名沒報到不算（可由執秘手動登記）。
- **代登記時貼上 LINE 接龍、登記同行的非社友**：在「🙋 代為登記參加」按「💬 貼上 LINE 接龍」，把 LINE 群組的接龍訊息複製貼上後按「分析」，系統會找出社友並勾選。寫「+1」＝帶寶尊眷（社友庫有寶尊眷資料就直接勾，沒有就留欄位給執秘填名字）；寫「+2」以上，第 2 位起請在下拉選單選「子女／外勞／朋友／其他」。找不到或同名的人會列出來請執秘手動處理，寫「取消」「請假」的會略過；按「套用到下方名單」後檢查一下再按「儲存」。社友帶了社友庫以外的人時，也可以在「同行的非社友」手動新增。同行者會出現在 LINE 參加名單（標示身分）、可以記錄實際出席，例會統計則算在「寶尊眷與同行者」人數裡。
- **記錄例會實際出席、看統計、匯出 Excel**：在「🗓️ 行事曆管理」的本社行程，每個例會有「✅ 記錄實際出席」按鈕，打開後分成兩組：上面是「有報名的人」（社友自己在 LINE 報名或執秘代登記），下面是「其他社友」（沒報名但臨時出席時在這裡勾選），寶尊眷排在對應社友下方；第一次打開會先勾好有報名的人，執秘依現場狀況調整後按「儲存出席紀錄」。「📊 例會統計」分頁可選本扶輪年度、上個扶輪年度、本月、上個月或自訂期間，看到各次例會的表示參加與實際出席人數，以及每位社友的參加次數與出席率（出席率只計算已記錄出席的場次），並可「⬇️ 匯出 Excel」（每位社友統計、各次例會、出席明細三個工作表）。
- **「私人」頁會顯示我參加的活動**：地區或社內活動，只要我按了「我要參加」或已經被執秘報名，就會自動出現在「私人」頁（標 🔗、保留原本的顏色，並標示「已報名」或「已表示參加」），取消參加後就不再顯示。
- **查看範圍**：今天、三天、本週、二週（本週起連續 14 天）、本月。
- **行程詳細頁**：顯示時間、地點、服裝、聯絡人與備註；地址可一鍵開 Google 地圖，電話可一鍵撥打。
- **新增／編輯**：所有社友都能新增自己的私人行程。社長、執秘被指定為「社內管理者」後可管理本社行程；地區辦公室被指定為「地區管理者」後可管理地區行程。可「複製」舊行程當範本、「取消行程」（保留但標示已取消）或「刪除」。
- **訂閱到手機行事曆**：行事曆右上角 ⚙️ 有開關。開啟後會產生專屬網址，貼到 iPhone 行事曆或 Google 日曆就會自動同步，由手機自己跳提醒（不需要 LINE 推播，不增加費用）。畫面附加入教學；網址包含私人行程，請勿外傳，外流時可「重新產生網址」讓舊網址失效，也可隨時關閉。
- **社內已報名名單與「我要參加」**：在「行事曆管理」新增或編輯行程時，可選「對應報名活動」（例如「運動賽事 › 地區高爾夫球比賽」）。社友在 LINE 打開這個行程，會看到**本社**誰已報名、誰表示要參加（別社看不到），並有「🙋 我要參加」按鈕。按下後名字立刻出現在社內名單；**這只是表示意願，正式報名仍由執秘確認後送出**。執秘在報名表上方會看到「社友在 LINE 行事曆按了『我要參加』」提示，可一鍵加入報名名單，確認欄位後按「送出本社報名表」。
- **活動日期自動進行事曆**：主委在「活動設定與費用金額」填 📅 活動日期（開始、結束時間選填，沒填＝全天），按「儲存主委設定」後，行事曆就會自動出現這個活動的地區行程，並自動對應該報名活動，社友在 LINE 看到就能按「我要參加」。之後改日期，行事曆跟著更新；清空日期，自動建立的行程會移除。地辦分攤金／配合款不需要活動日期。
- **在報名系統裡管理（電腦版，推薦）**：登入報名系統後按 **🗓️ 行事曆管理**。「本社行程」直接新增、修改、複製、取消、刪除（自動使用本社登入密碼）；「地區行程」需再輸入一次行事曆後台密碼；最高管理員另有「管理者與活動類型」分頁，並可複製貼到 LINE 圖文選單的行事曆網址。私人行程只有本人在 LINE 裡看得到，這裡不會出現。
- **📥 Excel 匯入行程**：在「本社行程」或「地區行程」按「📥 Excel 匯入」→「⬇️ 下載範本」→ 填好後「📂 選擇 Excel 檔」。系統會先預覽：可以匯入的標綠色，有錯誤的列標紅色並寫出原因（例如「日期看不懂」「缺少標題」），和現有行程「標題＋開始時間」相同的標黃色並略過（所以同一份檔案重複匯入不會變兩筆）；確認後按「確認匯入 N 筆」，完成畫面顯示「成功匯入 N 筆，略過 M 筆」。必填只有日期和標題；日期可寫 2026/12/5、2026-12-05、民國 115/12/5 或 Excel 日期；時間可寫 19:00、下午7:00；沒填開始時間＝全天；跨天活動填「結束日期」；活動類型找不到歸為「其他」；「開放我要參加」沒填＝是。一次最多 300 筆。執秘只能匯入自己社的行程，地區行程需要行事曆後台密碼。
- **指定管理者**：開 `admin-calendar.html`（也可在上面的「管理者與活動類型」分頁操作），輸入行事曆後台密碼，搜尋社友後按「設為本社管理者／地區管理者」。畫面會列出還沒有管理者的社。也可在這裡新增、改名活動類型。
- **一次性設定**：① 在 Supabase SQL Editor 執行 `supabase/sql/calendar.sql`；② 在 Finder 點兩下 `部署行事曆.command`，上傳雲端小程式並設定後台密碼。

- **總監每日推播**：每天晚上 8:00，系統自動把總監**明天**的行程（地區＋總監所屬社＋總監的私人行程）用 LINE 卡片推給總監，並給**總監秘書**一份副本；每筆行程顯示時間、標題、地點、服裝，點「查看詳情」直接打開那筆行程。明天沒有行程就不推。設定方式：行事曆後台 ① 搜尋總監按「設為總監」、搜尋總監秘書按「設為總監秘書」（兩人都要在 LINE 綁定過身分）；④ 可以先「預覽」或「📤 現在測試發送」（卡片標【測試】）。每天最多約 2 則，使用官方帳號的推播額度。

- **在 LINE 聊天室問行程**：社友在官方帳號的聊天室傳「行事曆」（今天＋明天）、「今天」、「明天」或「本週」（最近 7 天），系統會依他綁定的身分，立刻回覆一張**他自己的**行程卡片（地區＋本社＋自己的私人行程），點「查看詳情」直接打開那筆行程；還沒綁定的人會收到綁定連結。只有整句剛好是這幾個詞才會回覆（例如「明天見」不會），群組裡不回覆。回覆訊息不算推播額度。設定方式：點兩下 `設定LINE聊天回覆.command` 輸入官方帳號的 Channel secret，再到 LINE Developers 把 Webhook URL 設成雲端小程式的網址並開啟 Use webhook。

### 各社活動提醒推播（活動前一天自動提醒社友）

由系統管理者在行事曆後台「④-2 各社活動提醒推播（允許推播的社）」**逐社開放，預設全部關閉**。

- 開放後，系統在每個活動的**前一天**、指定的時間（整點，上午 8:00～晚上 9:00 可選，預設**晚上 8:00**）用 LINE 提醒該社「明天有活動」的社友。
- 對象：已按「我要參加」（含執秘代為登記）或已被執秘正式報名的社友，而且要在 LINE 綁定過身分。範圍是地區活動與該社的社內活動，私人行程不提醒。
- 一位社友只收到一則卡片，列出他明天參加的全部活動。
- **不重複**：活動主委當天已經用「LINE 推播提醒」推過的活動，同一位社友不會再收到這個活動的提醒；不同天則各推各的。總監與總監秘書已有每日推播，不再另外提醒。
- 每個已開放的社可以按「預覽」看明天會提醒誰，或按「📤 現在發送」立刻發送（正式發送，不是測試）。
- 每則提醒都會使用官方帳號的推播額度。

> 每個地區的資料庫要先執行一次 `supabase/sql/calendar_club_remind.sql`（內含資料表與每小時排程；其他地區要改裡面的網址與 LIFF ID）。

## 社費推播（執秘用 LINE 把社費明細推給每位社友）

**開放方式**：由系統管理者在行事曆後台「④-2 各社活動提醒推播」開放該社（同一個開關同時開放活動提醒與社費推播）。開放後，執秘在報名系統上方的快捷列會看到「💰 推播社費」。

1. **基本資訊**：期別（必填）、繳費期限、繳費方式、補充說明。
2. **共同品項**：每位社友都要繳的項目（名稱＋金額），可以多項。
3. **社友明細**：每位社友一列（不含寶尊眷），顯示 LINE 是否已綁定。
   - 不用繳某個共同品項的社友（例如榮譽社友），取消那一格的勾選。
   - 「＋加品項」可以替這位社友加任何項目，金額可以是負數（例如溢繳折抵 -2000）。
   - 小計為 0 的社友不會收到推播。
4. 按「預覽」確認：會收到的人數、沒綁定 LINE 收不到的社友（可按「複製明細文字」改用其他方式通知）、卡片內容範例。
5. 按「📤 用 LINE 發送」，確認人數後送出。每位社友收到一張卡片，**只看得到自己的明細**。

- 下次打開會自動帶出上次的共同品項與個別品項；沿用的個別品項標黃色「沿用上次」，請逐一確認。
- 填到一半關掉，內容會留在這台電腦的瀏覽器，下次打開繼續填（換電腦不會帶過去）。
- 不限發送次數；只有 60 秒內送出一模一樣的內容會被擋下（防止誤按兩次）。
- 每位社友的金額不會存進公開的報名資料；發送紀錄只記時間、期別、人數與總金額。
- 系統不記錄社友是否已繳社費。

> 每個地區的資料庫要先執行一次 `supabase/sql/club_dues.sql`。

## 全球獎助金查詢（找國際合作計畫）

報名系統上方的快捷列有「🌍 全球獎助金」，可以查詢全世界扶輪社正在募款的全球獎助金（Global Grants）計畫，方便找合作對象。資料來自公開網站 matchinggrants.org，每週一早上自動更新一次（系統管理者也可以手動更新），畫面上方會顯示「資料更新於…」。

- **全部計畫**：可用關鍵字、國家、區域、服務重點篩選，預設只列「還在募款中」的計畫。每筆顯示總金額、尚缺金額、主辦社、國際夥伴社與**聯絡人姓名、Email**（點 Email 可直接寫信）。
- **查看詳情**：計畫說明（中文為機器翻譯，僅供參考，可切換看英文原文）、已認捐明細、前往原始網站的連結。認捐等動作要到原始網站進行。
- **和本地區有關的計畫**：主辦社或國際夥伴社屬於本地區，或本地區（含所屬扶輪社）有認捐的計畫。目前沒有的話會顯示空白說明。
- **📥 匯出 Excel**：把目前篩選出來的計畫（含完整說明與聯絡人）下載成 Excel 檔，檔案只在自己的電腦上產生。
- 聯絡資訊僅供洽談合作使用，請勿用於群發信件。
- 這個功能只能查詢，不能修改計畫資料；查到的內容不會存進報名系統的資料庫。

> **開放／關閉某個地區（系統管理者）**：地區設定檔 `grantsEnabled` 設為 `true` 就會出現按鈕，不需要另外設定金鑰——共用資料庫 Rotary-Shared 的這張資料表已設成「公開唯讀」（任何人只能讀取，不能新增、修改、刪除；SQL 見 `supabase/sql/rotary_shared_readonly.sql`），雲端小程式用的是可公開的唯讀金鑰。要關閉某個地區：把 `grantsEnabled` 改回 `false`（隱藏按鈕），或在該地區的雲端小程式設 secret `GRANTS_DISABLED=1`（畫面顯示「本地區尚未開放全球獎助金查詢」）。詳細規格見 `讀取Rotary-Shared資料說明.md`。

## 活動照片找人・第一步：社友大頭照

活動結束後，系統會用社友的大頭照，從攝影師拍的活動照片裡找出每位社友的照片，再用 LINE 通知他。**目前完成的是第一步「建立大頭照」**；找照片與通知是之後的第二、三步。

**大頭照由執秘統一建置**：社友把大頭照傳給執秘（LINE、Email 都可以），執秘在報名系統上傳。社友不需要自己操作。

**執秘怎麼用**

1. 社友庫右上角按「📷 大頭照」，會列出本社每個人（含寶尊眷）有沒有大頭照、有幾張。
2. 視窗右上有「複製『請社友傳大頭照給我』的訊息」，可以貼到社的 LINE 群組。
3. 收到照片後，在那位社友那一列按「上傳」，可以一次選好幾張（每人最多 3 張）。上傳前系統會請您確認已取得本人同意。
4. 按「查看」可以看那位社友目前的照片，傳錯了可以「刪除這張」；社友要求不再使用時按「全部刪除」。

**照片怎麼挑**：正面、臉清楚、只有本人；最好 2～3 張（例如有戴眼鏡、沒戴眼鏡各一張）；請用近幾年的照片。

**請留意**

- 上傳後，有綁定 LINE 的社友會收到一則通知，告訴他執秘已幫他建立大頭照（讓本人知情）。
- 大頭照是敏感個資：存在不公開的空間，不會出現在報名系統的公開資料裡。
- 從社友庫刪除社友時，他的大頭照會一起刪掉。
- 這個功能要由地區系統管理者**逐社開放**（預設全部關閉）。沒開放的社看不到按鈕。

> **開放某個地區與某個社（系統管理者）**：① 在該地區的 Supabase 執行 `supabase/sql/member_portraits.sql`，並重跑 `supabase/sql/member_rename.sql`（社友改名時大頭照才會跟著搬）；② 部署雲端小程式 `line-checkin`；③ 地區設定檔 `photoEnabled` 設為 `true`；④ 在行事曆後台（`admin-calendar.html`）的「⑦ 活動照片找人」選社、按「開放」。

## LINE 自助報到（社友自己掃 QR Code 報到）

櫃台點名之外，社友也可以用自己的手機報到：用 LINE 掃會場張貼的 QR Code，按一下「確認報到」就完成，畫面會出現明顯的綠色「報到成功」。櫃台與主委後台會同步看到，紀錄上標示「LINE 自助」。

### 社友怎麼用

1. **第一次使用要先綁定**（只做一次）：掃 QR Code 後選分區、社別，再從名單點選自己的名字。名字只能從貴社的社友庫挑，不能自己輸入；一個名字只能綁一個 LINE 帳號。
2. **活動當天**：掃會場的 QR Code → 畫面顯示「○○社 王小明」→ 按「確認報到」。有一起報名的寶(尊)眷可以順便勾選一起報到。
3. 沒報名的人掃了會看到「您尚未報名本活動，請洽櫃台」，由工作人員決定是否現場加報。櫃台先幫他「現場加報（還沒到）」之後，他也可以自己掃碼報到。
4. 綁錯名字時，按畫面上的「不是我？重新綁定」。

### 主委

- 「活動報到」面板多一張「社友 LINE 自助報到 QR Code」，按「下載 QR Code 圖片」列印後張貼在會場。這張是**給社友掃的**，不需要報到密碼；另一張給工作人員的 QR Code 請不要弄混。
- 同樣只有「報到中」才有效；每個子活動各有一張。

### 執秘

社友庫右上角「📱 LINE 綁定名單」可以看到本社哪些人已經綁定（含他的 LINE 名稱與綁定時間），有人綁錯或換了 LINE 帳號時按「解除綁定」。

**社友改了姓名或 Nick Name（例如 PE 變 P、P 變 PP）**：在社友庫編輯並儲存後，系統會自動把他的 LINE 綁定、行事曆身分（管理者、總監、總監秘書）、私人行程、我要參加、出席與補出席紀錄，以及貴社已送出報名表上的名字，一起搬到新名字，他**不需要重新綁定 LINE**。若自動搬移沒有成功（畫面會提醒），或是用 Excel 整批匯入改的名字，請開「📱 LINE 綁定名單」：舊名字那一列會出現黃色警告，選擇他現在的名字後按「🔁 對應到現在的名字」即可。歷屆備份是當時的紀錄，不會跟著改名。

> 每個地區的資料庫要先執行一次 `supabase/sql/member_rename.sql`（Supabase → SQL Editor → 貼上 → Run）才有這個功能。

### 請留意

- 不防代報到：系統不檢查人是否真的在現場（不用定位、不用會變動的 QR Code），這是刻意的設計。
- 沒帶手機、沒有 LINE、沒綁定的人，一律到櫃台報到；協助綁定請不要在報到櫃台做，會塞住隊伍。
- 社友的 LINE 帳號代碼存在一般畫面與程式都讀不到的地方，連執秘也只看得到 LINE 顯示名稱。
- 「解除綁定」以貴社的登入密碼確認身分，防護程度與報名系統相同。

### LINE 自助報到設定（每個地區只需做一次）

1. 到 Supabase → SQL Editor，依序執行 `supabase/sql/event_checkins.sql`、`supabase/sql/line_bindings.sql`。
2. 在 LINE Developers 建立這個地區自己的 Provider（建立後無法搬移），底下建立 LINE Login 頻道與一個 LIFF 應用程式：Endpoint URL 填 `https://<網站網址>/line.html`，Scope 勾 `openid` 與 `profile`，大小選 Full。
3. 把 LIFF ID 填進地區設定檔 `config/districts/<代號>.json` 的 `lineLiffId`，重新產生設定並部署。
4. 部署雲端小程式：`supabase functions deploy line-checkin --project-ref <專案代號> --no-verify-jwt`，並設定 `LINE_LOGIN_CHANNEL_ID`（LINE Login 頻道的 Channel ID）；有用各社預設密碼的地區另設 `DEFAULT_CLUB_PASSWORD`。

沒有填 `lineLiffId` 的地區，畫面上不會出現任何 LINE 自助報到的按鈕，其他功能不受影響。

## LINE 推播提醒（提醒已報名的社友出席）

主委可以用地區的 LINE 官方帳號，傳訊息提醒「已報名這個活動」的社友。**這個功能預設關閉，由系統管理者逐一地區開放**；沒有開放的地區畫面上不會出現。

### 主委怎麼用

在主委後台點開「📣 LINE 推播提醒」：

1. **選對象**：先選發給誰——
   - **已報名這個活動的社友**（提醒出席用）；
   - **LINE 官方帳號的所有好友**（邀請大家報名用，例如年會）：不管有沒有報名、有沒有綁定，加了好友的人都會收到；有幾位好友就用掉幾則，且訊息不能用 `{姓名}`、`{社名}`。

   選「已報名的社友」時可再細分：全部報名者、只通知還沒報到的人、或只通知已報到的人；運動賽事可再選「只有參賽者／只有只用餐的人」。下方依分區列出有報名的社，可以整個分區或單一社勾選。
2. **寫訊息**：有預設內容可直接用。`{姓名}`、`{社名}`、`{活動名稱}` 發送時會換成每個人自己的資料。
3. **先看會發給幾個人**：輸入「推播密碼」後，會顯示符合條件的人數、其中幾人已綁定 LINE（收得到）、誰收不到，以及官方帳號本月剩餘的訊息則數。
4. **發送**：確認後送出。送出後無法收回。下方會留下這個活動的發送紀錄。

### 請留意

- **只有已經用 LINE 綁定姓名的社友收得到**（見「LINE 自助報到」）；而且他要把地區的 LINE 官方帳號加為好友。沒綁定的人會列在名單上，請另外通知。
- **每送給一個人算一則訊息**，計入 LINE 官方帳號的每月用量；超過方案額度可能送不出去或另外計費，費用由官方帳號的擁有者負擔。
- 「推播密碼」由系統管理者提供，與登入密碼、報到密碼都不同；這台裝置不會記住，重新整理後要再輸入。
- 同一個活動一分鐘內不能重複送出一模一樣的訊息，避免連點造成重複打擾。

### 開放某個地區使用（系統管理者）

1. 該地區要有 LINE 官方帳號，並啟用 Messaging API。**啟用時選的 Provider 必須與 LINE 自助報到的頻道相同**（否則認不出同一位社友），選了之後不能更改。
2. 到 Supabase → SQL Editor 執行 `supabase/sql/line_push.sql`。
3. 在雲端小程式 `line-checkin` 設定兩個 secret：`LINE_MESSAGING_ACCESS_TOKEN`（官方帳號的 Channel access token）與 `LINE_PUSH_PASSWORD`（自訂的推播密碼），並重新部署小程式。
4. 地區設定檔 `linePushEnabled` 改成 `true`，重新部署網站。

要關閉時，把 `linePushEnabled` 改回 `false` 並刪除兩個 secret 即可。

## 主委調整費用：已送出的報名表自動更新

主委在「活動設定與費用金額」修改費用（參賽費、只用餐、共同主辦／協辦／贊助社金額、社慶花款與餐費、研討會每社應繳金額、PELS 四種出席方式費用）後，這個活動**所有已送出的報名表**會自動依新費用重算應繳金額，各社不需要重新送出；繳費總表、匯款區塊的「本活動應繳」與自動核對入帳都會改用新金額，各社執秘開著的畫面也會即時更新。

- 分攤金／配合款是各社執秘自己填的金額，不會被重算。
- 已經核對為「已繳費」的社，金額變動後仍維持已繳費；系統會在提示中列出這些社，差額請主委另行處理。

## 多人同時使用：畫面自動更新（不需重新整理）

- 執秘按「送出本社報名表」後，自己的畫面直接更新；**主委如果正開著後台報名表，約 1 秒內會自動出現新的報名**，並跳出「○○扶輪社 剛送出報名表」提示，不需要重新整理網頁。
- 主委核訖繳費、上傳活動 DM、修改費用等，其他開著的畫面也會自動更新。
- 網路不穩漏掉通知時，系統每 15 秒會自己再檢查一次；手機從背景切回網頁時也會立刻檢查。
- 送出報名表前系統會先抓一次最新資料，避免兩個社同時送出時互相蓋掉。若沒有成功存到雲端，會跳出提示請您再按一次，勾選的內容不會消失。
- 主委正在後台輸入文字或開著彈出視窗時，畫面會等您輸入完才更新，避免打到一半被洗掉。

## 各社預設密碼與修改密碼

- 地區設定檔（`config/districts/<代號>.json`）的 `defaultClubPassword` 可以填一組「內定密碼」。有填的地區，所有社第一次都用這組密碼登入，登入畫面不再顯示「首次進入 (註冊)」。
- 執秘登入後，在報名頁的「⚡ 行動快捷功能」按 **🔑 修改密碼**：先輸入目前的密碼，再輸入兩次新密碼（至少 4 個字），就會改成自己的密碼。
- 執秘忘記密碼時，最高管理員到「最高權限管理」的密碼查詢卡片按「重置並清除此社密碼」，該社就會恢復成預設密碼。
- `defaultClubPassword` 留空的地區維持原本流程：各社到「首次進入 (註冊)」自行設定密碼。

## 地區設定（同一份程式給不同扶輪地區使用）

所有「地區專屬」的內容（地區名稱、年度、Logo、Supabase 連線、AI 小幫手網址、分區與社名冊）都不寫在 `index.html`，而是放在 `config/districts/<地區代號>.json`，由 `scripts/build-config.js` 轉成 `district-config.js` 給網頁讀取。

- 3523 的 `district-config.js` 已放在倉庫裡當預設值，所以直接開 `index.html`、GitHub Pages、現有 Vercel 專案都不需要額外步驟。
- 要改 3523 的名冊或年度：改 `config/districts/3523.json`，執行 `node scripts/build-config.js`，把產生的 `district-config.js` 一起 commit。
- 要給另一個地區用：複製 `config/districts/_template.json` 成 `<代號>.json` 填好，Logo 放 `assets/logo-<代號>.png`，在該地區的 Vercel 專案設定環境變數 `DISTRICT_CODE=<代號>`，部署時 `vercel.json` 會自動執行建置腳本換成該地區的設定。
- `supabaseAnonKey` 是可公開的 publishable 金鑰，資料安全靠 Supabase 端的 Row Level Security，不靠藏金鑰。
